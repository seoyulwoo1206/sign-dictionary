# 한국수어 동작 저작 어휘 (tools/ksl)

국립국어원 한국수어사전의 **수형 설명**을 읽고, 그 문장을 거의 낱말 그대로 옮겨 적어 3D 동작을 만드는 도구입니다.

- 사전의 **영상·사진에서 좌표를 뽑거나 따라 그리지 않습니다** (CC BY-NC-ND 2.0 KR). 설명 글을 읽고, 모호하면 수형 사진·항목 페이지를 **눈으로 보고** 이해한 뒤 여기 어휘로 새로 적습니다. 사전 이미지·영상을 프로젝트에 저장하지 않습니다.
- 수형 설명 원문은 `data/ksl-ref.json`에 그대로 있고, 생성기가 `ref`(사전 번호)로 찾아 `words.json`과 동작 JSON에 **원문 그대로** 넣습니다. 우리가 쓰는 `풀이`는 우리말로 다시 쓴 짧은 설명이어야 합니다(베끼지 않기).

| 파일 | 내용 |
|---|---|
| `signs/*.mjs` | 단어 동작 정의. 묶음마다 파일 하나(`batch-01.mjs` …). 폴더 안 모든 `.mjs`를 생성기가 읽는다 |
| `jamo.mjs` | 지문자 40개 |
| `vocab.mjs` | 어휘: 손 모양·위치·방향·부위·움직임 도우미, 정의 → 키포즈 풀기 |
| `engine.mjs` | 움직임 엔진: 최소 저크 타이밍, 곡선 경로, 몸 충돌 회피, 팔꿈치 고르기, 손목 한계, 눈 깜빡임 등 (보통 고칠 일 없음) |


## 0. 꼭 알아야 할 약속

**손가락 번호 (사전 표기)** — `1지 = 검지`, `2지 = 중지`, `3지 = 약지`, `4지 = 새끼(소지)`, `5지 = 엄지`.
(예: "오른 주먹의 5지를 펴서" = 엄지 척, "4지를 펴서" = 새끼손가락, "1·5지" = 검지와 엄지)

**좌우** — "오른손"은 수어하는 사람의 오른손 = 데이터의 `right`. 방향 `'왼'`/`'오른'`도 **수어하는 사람 기준**입니다(화면에서는 반대로 보임). 좌표로는 x+ 가 수어자의 왼쪽, y+ 위, z+ 밖(보는 사람 쪽). 길이 단위는 **어깨 너비 = 1** (약 38cm; 0.1 ≈ 4cm).

**사전 말투 → 어휘**

| 사전 표현 | 뜻 | 적는 법 |
|---|---|---|
| 밖으로 | 보는 사람(상대) 쪽 | `'밖'` |
| 안으로 / 몸 쪽으로 | 수어자 몸 쪽 | `'안'` |
| 바닥이 밖으로 | 손바닥이 상대 쪽 | `바닥: '밖'` |
| (손)등이 밖으로 | 손등이 상대 쪽 = 손바닥이 몸 쪽 | `등: '밖'` (= `바닥: '안'`) |
| 세운다 | 손끝이 위 | `끝: '위'` |
| 모로 세운 손 | 손날(새끼 쪽)이 아래, 손바닥이 옆(가운데 쪽) | `바닥: '중앙'`(오른손이면 `'왼'`) + `끝: '밖'` 등 |
| 끝이 왼쪽으로 | 손끝이 수어자의 왼쪽 | `끝: '왼'` |
| N지 옆면 | 손가락의 옆 | 부위 `'N지옆'`, `'손날'`(4지 옆면), `'엄지쪽'`(1·5지 옆면) |
| N지 끝 바닥 | 손가락 끝의 지문 쪽 | 부위 `'N지끝'` 또는 `'N지바닥'` |

## 1. 동작 정의의 모양

```js
// tools/ksl/signs/batch-02.mjs
import { 반복, 댄다, 두번댄다, 옮긴다, 흔든다, 손목흔든다, 원그린다, 모양바꾼다, 내린다 } from '../vocab.mjs';

export default {
  '단어': {                      // data/words.json 의 word 와 똑같이
    ref: 2372,                   // 사전 항목 번호 (data/ksl-ref.json 의 candidates[].no) — 동음이의어는 meaning 에 맞는 것을 고른다
    풀이: '우리말로 다시 쓴 한두 문장',   // → words.json description
    수형: '편 손',                // → handshape
    비수지: '고개를 살짝 숙인다',   // → nonManual (없으면 '')
    동작: [ 키, 키, ... ],         // 아래 참고. 마지막에 쉬는 자세로 내려가는 것은 자동
  },
};
```

### 키 (한 순간의 자세)

```js
{ 오른: 자세, 왼: 자세, 양손: 자세,   // 손 (적지 않은 손은 그대로 둔다). 양손 = 오른손 기준으로 적으면 왼손은 좌우를 뒤집어 똑같이
  시간: 8,        // 이 자세까지 가는 데 걸리는 프레임 수의 최소값(30fps). 먼 거리는 엔진이 알아서 늘린다
  멈춤: 3,        // 도착해서 멈춰 있는 프레임 수
  지나감: true,   // 멈추지 않고 지나가는 점 (다음 키와 한 흐름으로 이어진다 — 원·곡선 경로)
  표정: '밝음',   // 한 번 적으면 바꿀 때까지 유지
  머리: { 끄덕: 8 } }   // 이 키에서만 적용 (계속하려면 키마다 적는다)
```

### 자세 (손 한 개)

| 항목 | 뜻 | 예 |
|---|---|---|
| `모양` | 손 모양 (2장) | `'편손'`, `'1·5지 맞댐'` |
| `바닥` 또는 `등` | 손바닥(또는 손등)이 향하는 방향 (3장) | `바닥: '아래'`, `등: '밖'` |
| `끝` | 손끝(손가락 뿌리→끝)이 향하는 방향 | `'위'`, `'밖+0.5왼'` |
| `위치` | 어디에 (4장): 몸 위치, 몸 앞 공간, 반대 손의 부위, 또는 좌표 `[x, y, z]` | `'턱'`, `'몸앞'`, `'왼손등'` |
| `닿음` | 내 손의 **어느 부위**를 그 위치에 놓는가 (5장). 생략하면 닿는 위치는 `'손끝'`, 공간은 `'중심'`(손바닥 중심) | `'1지끝'`, `'손날'`, `'손바닥'` |
| `띄움` | 표면에서 띄우는 거리. 0(기본) = 닿음 | `0.1` |
| `옮김` | 그 자리에서 더 옮기는 양 | `{ 위: 0.1, 밖: 0.2 }` |
| `쪽` | 표면의 어느 쪽에서 닿는지 직접 정함 (손목·팔처럼 둥근 곳, 또는 띄움 방향을 정할 때) | `쪽: '위'` |
| `기울임` `꺾음` `비틂` | 손목만 돌리는 각도(도). 기울임 + = 엄지 쪽으로 까딱, 꺾음 + = 손바닥 쪽으로 굽힘, 비틂 + = 손바닥이 엄지 쪽으로 돌아감(바깥으로 비틂). 왼손·오른손 모두 같은 뜻(자동 대칭) | `기울임: 20` |
| `'내림'` | (자세 대신 문자열) 그 손을 쉬는 자세로 내린다 | `왼: '내림'` |

**이어 쓰기 규칙** — 적지 않은 항목은 그 손의 **앞 키 값을 그대로** 씁니다. 그래서 움직임은 바뀌는 것만 적으면 됩니다(`{ 오른: { 띄움: 0 } }`).
단, `위치`를 새로 적으면 `닿음·띄움·옮김·쪽`은 처음 값으로, `바닥/등/끝`을 새로 적으면 `기울임·꺾음·비틂`은 0으로 돌아갑니다. `옮김`은 다음 키에도 남으므로 제자리로 돌리려면 `옮김: {}`.
손이 처음 나올 때 빠진 항목의 기본값: `모양 '편손'`, `바닥 '중앙'`, `끝 '밖'`, `위치 '옆몸앞'`.

## 2. 손 모양

### 이름 붙은 모양

| 이름 | 사전 표현 | 모습 |
|---|---|---|
| `편손` | 손을 펴서 | 손가락을 붙여 편 손 |
| `편손벌림` | 손가락을 (활짝) 펴서 벌려 | 다섯 손가락을 벌려 편 손 |
| `주먹` | 주먹을 쥐고 | 엄지를 손가락 위에 얹은 주먹 |
| `가볍게쥔주먹` | 가볍게 주먹을 쥐고 | 느슨한 주먹 |
| `약간구부린손` | 손을 약간 구부려 | 손가락이 살짝 굽은 편 손 |
| `반구부린손` | 반쯤 구부린 손 | 손가락을 반쯤 굽힌 손 |
| `구부린손` | 손가락을 펴서 구부려 | 갈퀴처럼 손가락 마디를 굽힌 손 |
| `오므린손` | 손가락(끝)을 오므려/모아 | 다섯 손끝을 한데 모은 손 |
| `둥근손` | 둥글게 구부린 손 | C 모양 |
| `둥글게쥔손` | 둥글게 쥐고 | 컵을 쥔 듯한 손 |
| `꺾은손` | 손가락을 붙여 꺾어 | 손가락 뿌리만 직각으로 꺾은 손 |
| `동그라미` | (편 손의) 1·5지 끝을 맞대어 동그라미 | 나머지 손가락은 편 채 엄지·검지로 원 (지문자 ㅇ) |
| `쉬는손` | — | 힘을 뺀 손 |
| `지문자ㄱ` … `지문자ㅣ` | 'ㅅ' 손 모양 | 그 지문자의 손가락 모양(방향은 따로 적는다) |

### 손가락 표기 — "오른 주먹의 N지를 펴서 …"

`'<숫자 묶음>지 [수식어…]'` 꼴로 적습니다. **적은 손가락만 펴고 나머지는 주먹처럼 접습니다.** 수식어는 바로 앞 묶음에 걸립니다. 묶음을 여러 개 쓸 수 있습니다.

| 표기 | 사전 표현 |
|---|---|
| `'1지'` | 주먹의 1지를 펴서 |
| `'1·2지 벌림'` | 1·2지를 펴서 벌려 |
| `'1·2지 붙임'` / `'1·2지 약간벌림'` | 붙여 / 약간 벌려 (아무것도 안 쓰면 자연스럽게 조금 벌어짐) |
| `'5지'` / `'5지 세움'` | 5지를 펴서 (엄지가 옆으로) / 5지를 펴서 **세워**(엄지가 손끝 방향으로 곧게 — 엄지 척) |
| `'1·5지'` | 1·5지를 펴서 (ㄱ·ㄴ 모양, L자) |
| `'1·5지 맞댐'` | 1·5지 끝을 맞대어 (나머지는 접음. 나머지를 편 것은 `'동그라미'`) |
| `'1·2·5지 맞댐'` | 1·2지 끝과 5지 끝을 맞대어 |
| `'1·5지 약간구부림'` | 1·5지를 펴서 약간 구부려 |
| `'1·5지 둥글게'` | 1·5지를 펴서 (작은 잔을 쥔 듯) 구부려 |
| `'1·2지 구부림'` | 1·2지를 구부린다 (갈고리처럼) |
| `'1·2·3·4·5지 반구부림'` | 다섯 손가락을 반쯤 굽힌다 |
| `'1·2지 꺾음'` | 뿌리 마디만 직각으로 꺾음 |
| `'2·5지 1지 반구부림'` | 1지를 반쯤 굽히고 2·5지를 펴서 (묶음 두 개) |
| `'1지 5지 구부림'` | 1지는 곧게, 5지는 구부려 맞세움 |

수식어 전체: `벌림` `약간벌림` `붙임` `맞댐` `세움` `약간구부림` `둥글게` `구부림` `반구부림` `꺾음`.
한계: 벌림은 손 전체에 하나만 적용됩니다(예: ㅌ의 "2·3지는 붙이고 1지는 뗀다"는 정확히 못 만듦).

## 3. 방향

`'위'` `'아래'` `'밖'`(=`'앞'`) `'안'`(=`'몸쪽'`) `'왼'` `'오른'` 그리고 손 기준인 `'중앙'`(몸 가운데 쪽: 오른손이면 왼쪽) `'바깥'`(그 반대).
- 섞기: `'밖+위'`(45°), 비율: `'밖+0.5왼'`, 벡터도 가능 `[x, y, z]`.
- `끝`이 `바닥`과 수직이 아니면 `바닥`을 지키고 `끝`을 알아서 맞춥니다. 둘이 같은 축이면 오류.
- 두 손 대칭(`양손`)에는 `'중앙'`/`'바깥'`을 쓰면 편합니다(`'왼'`/`'오른'`은 왼손에서 자동으로 뒤집힘).

**중요 — 손목 한계**: 사람 손목은 70~80°쯤만 꺾입니다. 손끝 방향이 팔이 뻗어 오는 방향과 너무 다르면 엔진이 손을 돌려 버려서 적은 방향과 달라지고 움직임이 튑니다. 생성기가 `[주의] … 손목이 N° 꺾임`을 알려 주면 `끝`을 팔이 오는 쪽으로 조금 섞으세요. 요령:
- 오른손은 팔이 **오른쪽 아래·앞**에서 옵니다. 가슴 앞에서 손끝을 `'밖'`으로만 하지 말고 `'밖+0.6왼'`, 얼굴에 댈 때는 `'위'` 대신 `'위+0.5안'`(+조금 `'왼'`)처럼.
- 손끝이 `'아래'`인 모양(ㄱ·ㅅ·ㅜ)은 손을 조금 높이 들고 `'아래+0.3왼'`처럼 살짝 비스듬히.
- 얼굴 옆·어깨 뒤처럼 높고 뒤쪽인 곳에서 바로 내려오면 팔이 꼬입니다 → 마지막에 `지나감: true` 키로 앞쪽(`'어깨높이'`)을 한 번 거치게 합니다(`어제` 참고).

## 4. 위치

좌우가 있는 이름은 **그 손과 같은 쪽**을 뜻합니다(오른손의 `'눈옆'` = 오른쪽 눈 옆). 쪽을 정하려면 앞에 `왼`/`오른`을 붙입니다(`'왼가슴'`, `'오른볼'`).

**닿는 곳 (몸 표면)** — 손 부위가 표면에 얹힙니다. `띄움`으로 떼어 놓을 수 있습니다.

| 이름 | 곳 | 이름 | 곳 |
|---|---|---|---|
| `정수리` | 머리 꼭대기 | `턱` / `턱밑` | 턱 앞 / 턱 아래 |
| `이마` / `미간` | 이마 가운데 / 눈썹 사이 | `볼` | 뺨 |
| `눈` / `눈밑` / `눈옆` | 눈 / 눈 아래 / 눈 바깥 옆 | `귀` / `머리옆` | 귀 / 귀 위 옆머리 |
| `관자놀이` | 관자놀이 | `목` / `목옆` | 목 앞 / 목 옆 |
| `코` / `코옆` / `인중` | 코끝 / 콧방울 옆 / 코 밑 | `어깨` / `어깨앞` | 어깨 위 / 어깨 앞면 |
| `입` / `입옆` / `아랫입술` | 입 / 입꼬리 / 아랫입술 | `가슴` | 가슴 **중앙** |
| `옆가슴` (`왼가슴`·`오른가슴`) | 한쪽 가슴 | `명치` / `배` / `옆구리` | 명치 / 배 / 옆구리 |

**몸 앞 공간 (닿지 않는 곳)** — 손바닥 중심(또는 `닿음` 부위)이 그 점에 옵니다.

| 이름 | 곳 | 이름 | 곳 |
|---|---|---|---|
| `몸앞` / `가슴앞` | 가슴 앞 가운데(중립 공간) | `얼굴앞` / `옆얼굴앞` | 얼굴 앞 가운데 / 한쪽 |
| `옆몸앞` | 손과 같은 쪽 가슴 앞 | `입앞` / `눈앞` / `이마앞` | 입·눈·이마 앞 |
| `배앞` / `옆배앞` | 배 앞 | `귀옆` | 귀 옆 공간 |
| `목앞` | 목 앞 | `머리위` / `어깨위` | 머리 위 / 어깨 위 공간 |
| `어깨높이` | 손과 같은 쪽 어깨 앞 — 숫자·지문자를 보이는 자리 | `어깨너머` | 어깨 뒤쪽 |

**반대 손 기준 (왼손이 자리가 되는 수어)** — `'왼' + 부위`. 왼손 자세가 먼저(같은 키 또는 앞 키에) 있어야 합니다. 왼손이 움직이면 붙어 있는 오른손도 따라갑니다.
`'왼손등'` `'왼손바닥'` `'왼손끝'` `'왼손날'` `'왼엄지쪽'` `'왼손목'`(등 쪽) `'왼손목안'` `'왼1지끝'`…`'왼5지끝'` `'왼주먹앞'` `'왼팔'`(아래팔 가운데) `'왼팔0.3'`(0 = 손목 쪽 … 1 = 팔꿈치 쪽) `'왼팔꿈치'`.
손목·팔처럼 둥근 곳은 `쪽: '위'`처럼 어느 쪽에서 닿는지 적어 주세요. (왼손이 주가 되는 드문 경우는 `'오른손등'`처럼 반대로도 됩니다.)

## 5. 손의 부위 (`닿음`)

| 이름 | 부위 |
|---|---|
| `중심` | 손바닥 중심점(공간 위치의 기본) |
| `손끝` | 편 손가락들의 끝 |
| `N지끝` / `N지바닥` / `N지옆` / `N지등` / `N지뿌리` | N번 손가락의 끝 / 끝마디 지문 쪽 / 옆면 / 등 / 뿌리 마디 |
| `손바닥` / `손등` | 손바닥 / 손등 한가운데 |
| `손날` | 새끼 쪽 옆면 ("4지 옆면", 모로 세운 손의 아랫날) |
| `엄지쪽` | 검지·엄지 쪽 옆면 ("1·5지 옆면", 세운 주먹의 윗면) |
| `손가락바닥` / `손가락등` | 네 손가락의 가운데 마디 안쪽 / 바깥쪽 |
| `손목` / `손목안` / `손바닥뿌리` | 손목 등 쪽 / 안쪽 / 손바닥 아래쪽 |
| `주먹앞` | 주먹의 정면(첫 마디 등) |

부위가 표면을 **향하도록** 손 방향을 잡아야 합니다(예: 손바닥을 가슴에 대려면 `바닥: '안'`). 반대로 향하면 `[주의] … 향하지 않음`이 나옵니다.

## 6. 움직임 도우미

모두 **키 배열**을 돌려주므로 `...`로 펼쳐 넣습니다. 첫 인자는 `'오른'` `'왼'` `'양손'`. 마지막 객체에 `시간·멈춤·표정·머리`를 함께 줄 수 있습니다.

| 도우미 | 사전 표현 | 하는 일 |
|---|---|---|
| `댄다(손, { 시간, 멈춤 })` | …에 댄다 | 지금 위치에 띄움 0으로 붙이고 멈춘다 (앞 키에서 `띄움: 0.08`쯤 떼어 놓고 쓰면 다가가서 닿음) |
| `두번댄다(손, { 떼기: 0.09, 횟수: 2 })` | 두 번 댄다 / 두드린다 / 툭툭 친다 | 댔다 뗐다를 되풀이 |
| `옮긴다(손, { 밖: 0.2 })` | 내민다 / 당긴다 / 올린다 / 내린다 / 쓸어내린다 | 지금 자리 기준으로 옮김(값은 그 위치에서의 `옮김` 전체) |
| `흔든다(손, { 쪽: '왼', 폭: 0.08, 횟수: 2, 기준: {…} })` | 좌우로(상하로·전후로) 흔든다 | 폭만큼 왕복. `기준`은 흔들기 전의 `옮김` |
| `손목흔든다(손, { 종류: '기울임'\|'꺾음'\|'비틂', 각: 20, 횟수: 2 })` | 손목을 흔든다 / 돌린다 / 비튼다 | 손목만 왕복 |
| `원그린다(손, { 반지름, 면: '정면'\|'수평'\|'측면', 바퀴, 방향: ±1, 시작각, 기준 })` | 돌린다 / 원을 그린다 | 지금 자리에서 시작해 원을 돌아 제자리로 |
| `모양바꾼다(손, '주먹')` | 쥔다 / 편다 / 오므린다 / 접는다 | 손 모양만 바꿈 |
| `반복(n, 키…)` | 두 번 … | 키 묶음을 n번 |
| `내린다(손)` | — | 쉬는 자세로 (끝에서는 자동이라 필요 없음) |

도우미 없이 직접 적는 것들:
- **번갈아 / 엇갈리게**: 한 키에 `오른: { 옮김: { 위: .1 } }, 왼: { 옮김: { 아래: .1 } }`, 다음 키에 반대로 → `반복(2, …)`.
- **두 손 대칭**: `양손: { … }` (`'중앙'`/`'바깥'` 사용).
- **쓸어내린다 / 비빈다**: 닿은 채 `위치`를 바꾸거나(`'왼팔0.4'` → `'왼손등'`) `옮김`을 왕복.
- **튕긴다**: 짧은 `시간`(3~4)으로 `모양`을 바꾼다(`'1·5지 맞댐'` → `'1·5지'`).
- **곡선 경로(그린다)**: 중간 점들에 `지나감: true`.

### 표정·머리 (비수지)

- `표정`: `'보통'` `'밝음'` `'기쁨'` `'찡그림'` `'슬픔'` `'미안'` `'물음'`(눈썹 올림) `'놀람'` `'입벌림'` `'입다묾'` 또는 `{ 눈썹, 웃음, 입 }`(작은 수: 0.01~0.04).
- `머리`: `{ 끄덕: 도, 젓기: 도, 갸웃: 도 }` — 끄덕 + = 숙임, 젓기 + = 수어자의 왼쪽으로 돌림(다음 키에 −로 적으면 도리질), 갸웃 = 기울임. 보통 5~12°.
- 시선(손을 따라감)·눈 깜빡임·숨쉬기·어깨 움직임은 엔진이 알아서 넣습니다.

## 7. 예시 — 수형 설명을 정의로 옮기기

### (1) 감사합니다 — 왼손 위 접촉, 두 번
> 손끝이 밖으로 향하게 펴서 모로 세운 오른손의 4지 옆면을 손바닥이 아래로 향하게 편 왼 손등에 두 번 댄다.

```js
동작: [
  { 왼: { 모양: '편손', 바닥: '아래', 끝: '오른+0.5밖', 위치: '몸앞', 옮김: { 아래: 0.12, 왼: 0.08 } },   // 손바닥이 아래로 향하게 편 왼손
    오른: { 모양: '편손', 바닥: '왼+0.6안', 끝: '밖+0.6왼',      // 모로 세운 오른손, 손끝은 밖 (손목 때문에 살짝 왼쪽을 섞음)
            위치: '왼손등', 닿음: '손날', 쪽: '위', 띄움: 0.11 }, 시간: 11 },   // 4지 옆면(손날)을 왼 손등 위에 — 먼저 띄워 둔다
  ...두번댄다('오른', { 떼기: 0.1, 머리: { 끄덕: 8 } }),        // 두 번 댄다
],
```

### (2) 괜찮다 — 얼굴 접촉
> 오른 주먹의 4지를 펴서 끝 바닥을 턱에 가볍게 두 번 댄다.

```js
동작: [
  { 오른: { 모양: '4지', 바닥: '안+0.6왼', 끝: '위+0.55안', 위치: '턱', 닿음: '4지끝', 띄움: 0.07 }, 시간: 12, 표정: '밝음' },
  ...두번댄다('오른', { 떼기: 0.07 }),
],
```

### (3) 미안합니다 — 얼굴 → 왼손, 손 모양 변화
> 오른손의 1·5지 끝을 맞대어 동그라미를 만들어 이마에 댔다가 1·5지를 펴며, 손등이 위로 손끝이 오른쪽으로 향하게 편 왼 손등에 내려놓는다.

```js
동작: [
  { 오른: { 모양: '1·5지 맞댐', 바닥: '안+0.5왼', 끝: '위+0.4안', 위치: '이마', 닿음: '1지끝', 띄움: 0.05 },
    왼: { 모양: '편손', 바닥: '아래', 끝: '오른', 위치: '몸앞', 옮김: { 아래: 0.15, 왼: 0.1 } }, 시간: 12, 표정: '미안' },
  ...댄다('오른', { 시간: 4, 멈춤: 4 }),                         // 이마에 댔다가
  { 오른: { 모양: '편손', 바닥: '왼+0.6안', 끝: '밖+0.6왼', 위치: '왼손등', 닿음: '손날', 쪽: '위' },   // 펴며 왼 손등에 내려놓는다
    시간: 13, 멈춤: 8, 머리: { 끄덕: 12 } },
],
```

### (4) 기쁘다 — 두 손 대칭 + 번갈아
> 두 주먹의 1·5지를 펴고 손등이 밖으로 향하게 하여 1지 끝을 양쪽 가슴 앞에 대고 상하로 두 번 엇갈리게 움직인다.

```js
동작: [
  { 양손: { 모양: '1·5지', 등: '밖', 끝: '중앙', 위치: '옆가슴', 닿음: '1지끝', 쪽: '밖', 띄움: 0.06, 옮김: { 바깥: 0.02 } },
    시간: 11, 표정: '기쁨' },
  ...반복(2,
    { 오른: { 옮김: { 바깥: 0.02, 위: 0.1 } }, 왼: { 옮김: { 바깥: 0.02, 아래: 0.1 } }, 시간: 6 },
    { 오른: { 옮김: { 바깥: 0.02, 아래: 0.1 } }, 왼: { 옮김: { 바깥: 0.02, 위: 0.1 } }, 시간: 6 }),
  { 양손: { 옮김: { 바깥: 0.02 } }, 시간: 4, 멈춤: 2 },
],
```

### (5) 슬프다 — 두 동작 이어 붙이기, 원 그리기
> 오른 주먹의 1·5지를 펴서 끝을 맞대어 오른쪽 눈 밑에 댔다가 내린 다음, 손가락을 펴서 구부려 가슴에 대고 왼쪽으로 돌린다.

```js
동작: [
  { 오른: { 모양: '1·5지 맞댐', 바닥: '안+0.6왼', 끝: '위+0.3안', 위치: '눈밑', 닿음: '1지끝', 띄움: 0.05 }, 시간: 12, 표정: '슬픔' },
  ...댄다('오른', { 시간: 4, 멈춤: 3 }),
  ...옮긴다('오른', { 아래: 0.17, 밖: 0.03 }, { 시간: 10, 멈춤: 2 }),            // 내린 다음
  { 오른: { 모양: '구부린손', 바닥: '안', 끝: '위+0.6왼', 위치: '가슴', 닿음: '손끝', 옮김: { 오른: 0.02, 위: 0.07 } },
    시간: 10, 멈춤: 1, 머리: { 끄덕: 5 } },                                      // 구부린 손을 가슴에 대고
  ...원그린다('오른', { 반지름: 0.075, 면: '정면', 방향: 1, 시작각: 90, 기준: { 오른: 0.02, 위: 0.07 }, 머리: { 끄덕: 5 } }),   // 돌린다
  { 오른: {}, 시간: 3, 멈춤: 4 },
],
```

### (6) 지문자 ㄱ·ㅘ — 방향만 다른 같은 손 모양
> ㄱ: 오른 주먹의 1·5지를 펴서 1지 끝이 아래로 손등이 밖으로 향하게 세운다.
> ㅘ: 오른 주먹의 1지를 펴서 끝이 위로 등이 밖으로 향하게 세운 다음, 손목을 돌려 바닥이 밖으로 향하게 세운다.

```js
// ㄱ
[{ 오른: { 모양: '1·5지', 등: '밖', 끝: '아래+0.3왼', 위치: '어깨높이', 옮김: { 위: 0.14, 중앙: 0.04 } }, 시간: 9, 멈춤: 8 }]
// ㅘ = ㅗ 자세 → ㅏ 자세
[{ 오른: { 모양: '1지', 등: '밖', 끝: '위', 위치: '어깨높이' }, 시간: 9, 멈춤: 5 },
 { 오른: { 바닥: '밖', 끝: '위' }, 시간: 7, 멈춤: 7 }]
```
(`jamo.mjs`는 이것을 표로 줄여 적어 두었습니다.)

## 8. 점검

1. **생성기 경고**
   - `손목이 N° 꺾임` → 3장의 요령대로 `끝`을 고친다. 80° 언저리는 넘어가도 되지만 90° 이상은 고칠 것.
   - `'부위'이(가) '위치' 쪽을 향하지 않음` → 손 방향(바닥/끝)이나 `닿음` 부위가 틀렸다.
   - 오류(모르는 이름 등)는 단어와 몇 번째 키인지 알려 준다.
2. **수치 검사** — 뼈 길이 일정, 몸 뚫음 없음, 속도·가속도 튐, 시작·끝 중립. 팔꿈치 가속도가 유난히 크면(150/s² 이상) 손이 어깨·머리 바로 옆을 스치는 경로이거나 손목이 한계를 넘은 것 → 자세를 조금 앞으로 빼거나 `시간`을 늘린다.
3. **눈으로 보기** — `http://localhost:8770/#/word/<단어>` 에서 정면·측면, 멈춘 화면, 손 확대. 사전의 수형 사진과 나란히 비교한다. 바뀐 JSON은 `fetch(url, { cache: 'reload' })` 뒤 새로 고침.
   아바타는 데이터와 체형이 달라(머리가 크고 손이 큼) 얼굴 접촉이 조금 다르게 보일 수 있다. 데이터에서는 손 부위가 표면에 정확히 얹혀 있다.

## 9. 알아 둘 것 (한계)

- 손가락 벌림은 손 전체에 하나, 손가락 굽힘은 마디 두 개([뿌리, 가운데])로만 표현한다. 손가락을 꼬거나 한 손가락만 벌리는 모양은 근사치다.
- 두 손이 서로 뚫지 않게 막는 것은 뷰어(아바타) 쪽에서만 한다. 데이터에서는 `닿음`/`띄움`으로 정확히 놓아야 한다.
- `'왼팔'`·`'왼팔꿈치'` 위치는 팔꿈치 자리를 어림해서 정한다(실제와 몇 cm 다를 수 있음).
- 몸통 표면 위치에 `옮김`을 주면 표면을 따라가지 않고 직선으로 옮긴다(조금 뜨거나 파묻히면 엔진이 밀어낸다).
- 사전에 항목이 없는 단어는 만들지 않는다(지문자로 표시됨). 같은 수어를 쓰는 다른 표제어가 있으면 그 번호를 `ref`로 쓰고 `풀이`에 밝힌다(예: `밥` → ‘먹다, 식사’).
