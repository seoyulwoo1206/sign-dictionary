**지금 이용하고 있는 방식**

- 3D 아바타가 한국수어 단어 541개와 지문자 40개를 보여 줍니다.
- 각 단어 화면에 한국수어사전의 수형 설명을 **원문 그대로** 출처(저작자표시-비영리-변경금지 2.0 대한민국)와 함께 싣고, 사전 항목으로 가는 링크를 붙였습니다.
- 3D 동작은 사전 영상을 쓰지 않고, 수형 설명 글을 읽고 직접 새로 만들었습니다. 그래서 실제 수어와 다른 부분이 있을 수 있습니다.

**요청드리는 것**

사전의 수어 **영상**을 보고 3D 동작을 더 정확하게 만들고 싶습니다. 구체적으로는 다음과 같습니다.

1. 영상 속 손·팔·얼굴의 위치를 컴퓨터로 추출해 3D 아바타 동작 데이터로 바꾸는 것
2. 그렇게 만든 동작 데이터를 위 사이트에서 무료로 공개하는 것 (출처 표시, 비영리)

현재 라이선스의 '변경금지' 조건 때문에 1·2가 허용되는지 판단하기 어려워 문의드립니다.
허락해 주신다면 조건(출처 표기 방식, 이용 범위, 기간 등)을 그대로 지키겠습니다.
허락이 어렵다면 지금처럼 설명 글만 참고하는 방식을 유지하겠습니다.
